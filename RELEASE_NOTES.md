# CaptureBridge Hub v1.0.12

Highlights:

- build the portable release with Pillow 13.0.0, which fixes the security
  advisories published for Pillow 12.3.0 on 2026-10-20; and
- require Pillow 13 for source installs, which needs Python 3.11 or newer.

The Hub source code, protocol, and lag-test analysis are unchanged from
v1.0.11.

Install the matching CaptureBridge Android v1.0.17 APK. Use an authorized USB
connection or an isolated, trusted private network.
