# CaptureBridge Hub v1.0.9

This release is the Hub version archived for the CaptureBridge SoftwareX
submission.

Highlights:

- audited and exactly pinned portable-release dependencies;
- atomic, size-limited, operator-authorized incoming file transfers;
- interrupted-transfer cleanup and expanded automated tests;
- push/pull-request CI and dependency auditing;
- a SHA-256 checksum beside the portable ZIP; and
- explicit trusted-network and validation-scope documentation.

Install the matching CaptureBridge Android v1.0.15 APK. Use an authorized USB
connection or an isolated, trusted private network.
